# FineBI 看板搭建手册（对应 15 条 SQL）

> 目标：把 `sql/` 里的 15 条查询，在 FineBI 里做成 **1 个仪表板、3 个页面、15 个组件**。
> 每个组件都标明：图表类型、维度/指标、聚合方式、筛选、排序、标签格式，照着拖即可。

---

## 0. 先想清楚：哪些在 SQL 算，哪些在 BI 算

这是最容易踩坑的地方。**不要**把 15 条 SQL 的结果各建成一张表再画图——
那样筛选器无法联动，数字也会二次聚合出错。

| 路线 | 适用查询 | 做法 |
|---|---|---|
| **A. BI 内聚合**（推荐） | Q01–Q04、Q07、Q09–Q12 | FineBI 直接连 `data` 明细表，拖维度+指标现场算 |
| **B. SQL 结果表** | Q05、Q06、Q08、Q13、Q14、Q15、Q12 的累计占比 | 窗口函数（`LAG/LEAD/RANK/NTILE/DENSE_RANK`）在 BI 里难复现，先跑 SQL 存成结果表/自助数据集，BI 只做展示 |

> 判断标准：**指标是"按维度重新聚合"就能算的 → A；需要行间比较（上一行、排名、累计）→ B。**

## 1. 开工准备（30 分钟，只做一次）

### 1.1 建数据连接

1. `管理系统 → 数据连接 → 新建 → MySQL`
2. 填主机 / 端口 / 库名 / 账号，测试连接
3. `数据准备 → 添加表 → 选 data 表`，确认字段类型：
   - `Churn` = 数值（0/1）
   - `TotalCharges`、`MonthlyCharges` = 数值
   - `tenure` = 数值
   - 其余为文本

### 1.2 建 3 个计算字段（"数据准备"里添加）

| 字段名 | 公式 | 用途 |
|---|---|---|
| `流失人数` | `SUM(Churn)` → 在组件里用「求和」 | Q01/Q02/Q03 |
| `流失率` | `Churn` 拖入指标后设「平均」，再设百分比格式 | 全局 |
| `MRR损失` | `MonthlyCharges` 拖入指标设「求和」，加过滤 `Churn = 1` | Q11 |

> 格式设置：指标 → 数值格式 → 百分比、保留 2 位小数。

### 1.3 建仪表板

新建仪表板，命名 **Telecom Churn Analysis**，建 3 个 Tab：

| Tab | 内容 | 组件 |
|---|---|---|
| ① 总览 | 大盘数字 + 时间线 + 合同结构 | Q01、Q04、Q05、Q11 |
| ② 归因 | 人群、服务、支付组合 | Q02、Q03、Q07、Q09、Q10 |
| ③ 名单 | 可执行的高价值/高危名单 | Q06、Q08、Q12、Q13、Q14、Q15 |

全局放 3 个过滤组件（下拉框）：`Contract`、`PaymentMethod`、`InternetService`，设为「作用于全部组件」。

### Q12 · 营收集中度 → **营收二八饼图（已落地）**

> 历史问题：早期那张图的 X 轴是用户名、Y 轴只到 0.53，容易被读成 53%。
> **现已改为饼图**，落地在图③「营收二八定律」。

| 项 | 配置 |
|---|---|

| 图例 | 同时显示两类用户的营收占比 |
| 标题 | 「Top 10% 用户贡献 30.83% 营收」 |
| 结论 | 比经典 80/20 更平缓；但头部单人价值是均值 3.8 倍 |

**如果想升级成累计曲线（可选，非当前版本）**：跑下面的 SQL 得到「用户百分位 vs 累计营收占比」，
再画折线，X 轴 0–100、Y 轴 0–100，标出 Top 20% → 53.63、80% 营收 → 38.4% 用户。

```sql
-- 用户百分位 vs 累计营收占比（0–100%）
WITH r AS (
  SELECT TotalCharges,
         ROW_NUMBER() OVER (ORDER BY TotalCharges DESC) AS rn,
         SUM(TotalCharges) OVER () AS total,
         SUM(TotalCharges) OVER (ORDER BY TotalCharges DESC) AS cum
  FROM data
)
SELECT ROUND(rn * 100.0 / COUNT(*) OVER (), 2) AS user_pct,
       ROUND(cum * 100.0 / total, 2) AS revenue_pct
FROM r;
```

**做法 B（路线 A，快速版）**：用「分组表」按 `TotalCharges` 十分位（`NTILE` 等价：排名/总数）分组，
指标用「快速计算 → 累计占比」，同样得到 0–100% 的曲线。
