# A/B 实验设计：新客护航计划（Onboarding Guard）

> 目的：验证「新客护航计划」能否把 **0–6 个月新客流失率** 从 52.94% 显著压低。
> 本文只描述**实验设计与分析口径**；仓库里的 `src/abtest_analysis.py` 用模拟数据演示整套统计流程。

---

## 1. 业务假设

| 项 | 内容 |
|---|---|
| 观察 | 报告 Q04：0–6 个月新客流失率 52.94%，首月高达 62%，是全生命周期最高点 |
| 假设 H1 | 在入网第 7 / 30 / 60 / 90 天做四次主动触达（激活指引 → 用法答疑 → 首月账单体检 → 权益提醒），可降低该人群流失率 |
| 原假设 H0 | 实验组与对照组流失率无差异 |
| 备择假设 H1 | 实验组流失率低于对照组（单侧业务判断，但统计上按双侧检验报告） |

**为什么值得做**：流失用户平均月租 74.44 元，若能把新客流失率压低 4pp，
按 1,481 名新客测算，一年约少流失 59 人、保住月租约 5.3 万元；且新客留存会沿生命周期持续放大。

---

## 2. 指标定义

| 类型 | 指标 | 口径 |
|---|---|---|
| **主指标（Primary）** | 入网 90 天流失率 | 实验期内注册的新客，在注册后第 90 天是否已流失（0/1） |
| 次指标（Secondary） | 首单合同绑定率 | 新客是否在首月内绑定一年期及以上合同 |
| 次指标 | 首月 ARPU | 注册后首个完整账单周期的月租 |
| **护栏指标（Guardrail）** | 投诉率 | 每千名新客的投诉工单数，上升 >20% 视为不可接受 |
| 护栏指标 | 触达退订率 | 主动触达的退订比例 |
| 诊断指标 | 触达打开率 / 结案率 | 判断是"没触达"还是"触达了但没用" |

> 主指标只有一个，避免多重比较；其余指标只做描述性报告，不做显著性宣称（除非做 FDR 校正）。

---

## 3. 实验单位与分流

- **随机化单位**：`customerID`（用户级），不做集群随机化，因为触达是个体级的
- **分流比例**：50 : 50
- **分层随机（stratified randomization）**：按 `Contract`（月付/一年/两年）× `InternetService`（光纤/DSL/无）分层，保证两组结构一致
- **SRM 检查**：上线后 24h 内做卡方拟合优度检验（`srm_check()`），p < 0.01 立即停止并排查分流链路
- **互斥性**：与同期其他挽留实验做流量互斥，同一用户 30 天内不进入第二个挽留实验

---

## 4. 样本量与周期

由 `src/abtest_analysis.py` 的功效分析给出（α = 0.05，power = 0.80，双侧）：

| 参数 | 取值 |
|---|---|
| 基线流失率 p₀ | 52.94% |
| 最小可检测效应 MDE | **4.0 pp**（52.94% → 48.94%） |
| 显著性水平 α | 0.05（双侧） |
| 统计功效 1−β | 0.80 |
| **每组所需样本** | **2,451** |
| 两组合计 | 4,902 |

**周期估算**：以每月新增约 1,800 名新客计，达到 4,902 例约需 **2.7 个月**。
若希望缩短周期，可把 MDE 放宽到 5pp（样本量降到约 1,570/组），但要接受"更小的真实收益测不出来"的风险。

> MDE 的选择必须由**业务最小可行动收益**倒推：一次挽留动作成本约 20 元，
> 低于 3pp 的改善扣掉成本后所剩无几，因此不追求更小的 MDE。

---

## 5. 分析计划（Pre-registration）

1. **ITT 分析**：所有被随机分组的用户都计入分析，无论是否真的收到触达（避免选择偏差）
2. **主检验**：双样本比例 z 检验（合并方差），双侧 p < 0.05 且 95% CI 不含 0 才判定显著
3. **效应量**：同时报告绝对提升（pp）、相对提升（%）与 **NNT**（需要触达多少人才能多留住 1 人）
4. **稳健性**：Wald CI + 自助法 CI（4,000 次重抽样）双报告
5. **分层分析**：按 `Contract` 拆开看异质性，用于下一轮策略定向；分层结论标注为"探索性"
6. **不停看**：实验期内不做期中显著性判断（避免 peeking 导致假阳性）；
   若必须提前看，采用序贯检验（alpha spending）并预先固定检验次数

### 决策规则

| 结果 | 动作 |
|---|---|
| 显著为正、护栏无恶化 | 全量上线，纳入新客 SOP |
| 显著为正、但护栏恶化 | 优化触达频次后重测 |
| 不显著、CI 跨 0 | 判定"无充分证据"，不做全量；可提高 MDE 或扩大样本 |
| 显著为负 | 立即下线，复盘触达内容 |

## 6. 模拟结果（`python src/abtest_analysis.py`）

> ⚠️ 以下为**模拟数据**跑出的结果，用于演示统计口径与决策流程，不代表真实投放效果。

| 指标 | 结果 |
|---|---|
| 每组样本 | 2,451（合计 4,902） |
| 对照 / 实验流失率 | 52.59% / 47.16% |
| 绝对提升 | **−5.43 pp**（95% CI −8.22 ~ −2.63） |
| 相对提升 | −10.32%（95% CI −15.63 ~ −5.00） |
| p 值 | 0.0001 |
| NNT | 18.4 |
| SRM | 通过（实验组占比 50.00%） |

分层（探索性）：

| 分层 | 每组样本 | 基线 | 观测提升 | p 值 |
|---|---|---|---|---|
| Month-to-month | 1,470 | 60% | −5.99 pp | 0.0011 |
| One year | 1,470 | 35% | −1.63 pp | 0.3522 |
| Two year | 1,470 | 14% | −0.75 pp | 0.5545 |

**解读**：效果几乎全部来自月付用户——与报告中"月付 + 电子支票"是最高危组合一致。
因此下一轮实验应只对月付新客开放，用同样的预算换更大的绝对收益。

---

## 7. 局限

- 90 天窗口只能观察短期流失，长期留存需做 6/12 个月的跟踪分析
- 触达可能带来"霍桑效应"（被关注本身就降低流失），需设置空白对照（只记录不触达）
- 同期若有资费调整、竞品促销，会污染结论，需在分析中纳入时间固定效应
